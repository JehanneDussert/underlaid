# Refonte D4 — maquettes de référence

Maquettes validées le 3 octobre 2026. Les images (`png/`) sont la référence visuelle ; les fichiers `sources/*.dc.html` donnent les valeurs exactes (couleurs, tailles, espacements, textes, animations) mais s'appuient sur un moteur de maquettage : **ne pas les copier tels quels dans le site**, les lire comme une spécification.

Tout ce qui est **entre crochets** est fictif ou à compléter. Les durées sans crochets sont des médianes provisoires de la métropole (mardi 10 h). Les cartes sont des **illustrations** (géographie inventée).
