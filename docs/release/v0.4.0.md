## Underlaid v0.4.0 — retired indicators removed from the published data

**Draft.** Version number and date to be set when the release is created.

### Removed from the published data

The downloadable neighbourhood file (`vulnerability_score_iris.geojson`) no longer contains eight columns from four indicators that the project abandoned. None of them is part of the score, and the site no longer shows any of them:

| Columns | Indicator | Why it was abandoned |
|---|---|---|
| `access_minutes_domain_C`, `access_minutes_domain_D`, `access_minutes_domain_E` | Time to the nearest equipment (INSEE 200 m grid) | Crushed against its floor (most neighbourhoods at one or two minutes): it did not tell neighbourhoods apart. Replaced in v0.2.0 by access to care weighted by capacity (E2SFCA). |
| `social_index_schools`, `social_index_middle_schools` | Social position index (IPS) of the schools in the neighbourhood | It follows residents' income by construction, which the project measures on a separate axis. |
| `pct_pmr_accessible`, `erp_count` | Acceslibre, accessibility of building entrances | Coverage too uneven between départements: a missing entry means missing information, not an inaccessible place. |
| `footway_density_m_per_km2` | Density of footways mapped in OpenStreetMap | It measures how pavements are drawn in OpenStreetMap, which differs strongly between départements, not the pavements themselves. |

**These columns remain available in v0.3.0** on Zenodo: https://doi.org/10.5281/zenodo.23401610. Every other column and value of the file is unchanged (checked: the new file equals the v0.3.0 file minus these columns).

### Removed from the pipeline

Scripts `07_equipment_access_200m.py`, `09_social_index_schools.py`, `12_accessibility_erp.py` and `15_pedestrian_paths.py`, their intermediate files and their configuration. The quarterly update no longer downloads these sources.

### Sources no longer used

INSEE "Données sur la localisation et l'accès de la population aux équipements"; Ministry of Education "Indices de position sociale des écoles", "Indices de position sociale des collèges" and "Adresse et géolocalisation des établissements d'enseignement des premier et second degrés"; Acceslibre; the OpenStreetMap Overpass API (the OpenStreetMap street network is still used for travel times).
